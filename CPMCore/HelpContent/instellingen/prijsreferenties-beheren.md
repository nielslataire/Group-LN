## Een code toevoegen

De bovenste rij van de tabel is het formulier voor een nieuwe code.

1. Controleer het **codenummer**. CPM stelt het eerstvolgende vrije voor.
2. Typ de **omschrijving**, de **prijs per m²**, de **datum** en de **bron**.
3. Kies een **project** als de code enkel daar geldt. Laat je **Algemeen** staan, dan geldt ze voor elk project.
4. Klik op **Toevoegen**.

## Een code aanpassen

Klik op het potlood. De rij wordt een formulier. Pas de velden aan en klik op het vinkje. Met het kruisje annuleer je.

## Een code archiveren of verwijderen

Een code die nog in geen enkel budget staat, verwijder je met de prullenbak en een bevestiging.
Een code die al gebruikt is, archiveer je. Een gearchiveerde code staat grijs in de lijst.

## Exporteren

Klik bovenaan op **Exporteren** voor een Excel-bestand met de codes van het tabblad.

## Let op

Een prijswijziging past bestaande budgetten niet aan. Pas de prijs dus pas aan als je ze voor nieuwe budgetten wilt gebruiken.
